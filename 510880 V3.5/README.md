# free-stockdb-510880 · V3.5

510880（红利ETF）长期资料库 + 年线策略回测框架。

> ⚠️ **数据红线**：腾讯前复权(qfq)对 510880 的数据是**错的**（波动约2倍），
> 会让回测收益虚高约一倍。**回测只用 新浪不复权 或 腾讯 hfq，禁用 qfq。**
> 详见 `数据口径说明.md`、`修正记录-数据口径.md`。

## 最常用：每日体检（双击就行）

> **Windows**：双击根目录的 **`每日体检.bat`**
> **Mac**：双击根目录的 **`每日体检.command`**
>
> 它会自动联网更新数据，然后告诉你：最新价、年线、偏离度、买卖点价位、今天该不该动。

## 策略规则（双轨制 · 2026-10-02 定稿）

**轨道一 · 主仓轨**（满仓复利滚动，保底、防踏空）
- 买入：偏离度 ≤ 0（价格 ≤ 年线）→ 尾盘满仓买入
- 卖出：偏离度 ≥ **+5%**（价格 ≥ 年线×1.05）→ 尾盘清仓
- 每次买入金额 = 上次卖出后的全部资金（复利）
- ⚠️ 主仓轨**不可砍**：有些行情全程跌不到 -5%，只有它在干活

**轨道二 · 极限轨**（用「反正要留」的闲钱，不动主仓本金，重锤吃深坑）
- 买入：首次跌破 **-5%**（价格 ≤ 年线×0.95）→ 一次性全投
- 卖出：涨到 **+7.5%**（价格 ≥ 年线×1.075）→ 全卖
- 与主仓轨**买点零重叠**（一个买「浅跌破」、一个买「深坑」），资金相互独立

> 建议资金配比 **主仓 : 极限 ≈ 2 : 1**（金额只影响绝对规模，不影响年化）。
> 完整规则见《我的ETF年线交易系统》§1.1；本库是它的「数据 + 回测 + 体检」实现。

**关于 RSI（仅研究用）**
- `indicators.py` 里的 RSI 计算（标准 Wilder）**仅保留用于研究**；
- **主策略的买入 / 卖出只依据「偏离度」，不使用 RSI**。

## 口径说明

- **价格用不复权**（与你交易软件显示的年线一致）；
- 年线 = MA250；
- **成交逻辑**：信号**盘中实时监控**（偏离度触达）→ **下单固定在尾盘（收盘前 20 / 10 分钟）**，以届时价格成交；**回测中以「当日收盘价」近似**。
- 数据源交叉验证：新浪（不复权）+ 腾讯（前复权），交易日历比对。
