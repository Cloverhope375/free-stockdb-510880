# free-stockdb-510880 · V3.2

510880（红利ETF）长期资料库 + 年线策略回测框架。

> ⚠️ **数据红线**：腾讯前复权(qfq)对 510880 的数据是**错的**（波动约2倍），
> 会让回测收益虚高约一倍。**回测只用 新浪不复权 或 腾讯 hfq，禁用 qfq。**
> 详见 `数据口径说明.md`、`修正记录-数据口径.md`。

## 运行

```bash
pip install -r requirements.txt
```

## 切换起算年份（config.json）

改 `"start_date"` 即可，越晚起算越能避开 2008 / 2015 大顶：

| start_date | 主仓年化 | 应急金年化 | 主仓最大回撤 |
|---|---|---|---|
| 2007-01-01 | 0.14% | 3.67% | 65.8% |
| 2014-01-01 | 6.13% | 10.31% | 26.1% |
| 2018-01-01 | 7.64% | 12.64% | 21.2% |

> 注：MA250 用**全历史**预热后再截取，避免前 250 行指标为空。

## 策略规则（对齐"红利年线策略"定稿）

**主仓**（满仓复利滚动）
- 买入：偏离度 ≤ 0（价格 ≤ 年线）→ 尾盘满仓买入
- 卖出：偏离度 ≥ +7.5% → 尾盘清仓
- 每次买入金额 = 上次卖出后的全部资金（复利）

**应急金**（用"反正要留"的闲钱，不动主仓本金）
- 买入：首次跌破 -5%（价格 ≤ 年线×0.95）→ 一次性全投
- 卖出：涨到 +7.5%（价格 ≥ 年线×1.075）→ 全卖

## 口径说明

- **价格用不复权**（与你交易软件显示的年线一致）；
- 年线 = MA250；
- **尾盘下单**（以收盘价近似）；
- 数据源交叉验证：新浪（不复权）+ 腾讯（前复权），交易日历比对。
